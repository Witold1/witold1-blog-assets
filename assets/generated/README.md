# assets/generated/

Built output only. Do not edit by hand.

Run from the repo root:

```bash
npm install
npm run optimize
```

CI publishes this folder to GitHub Pages. The site should link keys under this tree via `mediaBaseUrl` / `NEXT_PUBLIC_MEDIA_BASE_URL` (for example `https://witold1.github.io/witold1-blog-assets/`).
